# Capturas

Las capturas de comprobación de cada versión de desarrollo no se publican: se generan en cada equipo con

```bash
python tools/devrun.py run visual -- .venv/Scripts/python.exe tools/visual_check.py docs/capturas/local
```

Aquí solo está `v22/explorador_iconos.png`, que muestra la familia de iconos AERO tal como la dibuja el Explorador
de Windows. Las capturas de la web están en `website/assets/capturas`.
